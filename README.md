# mxggle/tap

Homebrew casks for [PhraseLens](https://github.com/mxggle/phrase-lens).

```bash
brew install --cask mxggle/tap/phraselens
```

PhraseLens updates itself in-app, so `brew upgrade` skips it unless you pass `--greedy`.

The cask is updated automatically by the PhraseLens release script.
